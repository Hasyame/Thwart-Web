# Achievements — translation keys

Both clients carry every key below, in French and English. Names and
descriptions of achievements are keyed by the achievement's id, so a
wording change never touches the definitions file. Placeholders are in
braces; both clients substitute them, never reorder the arguments.

## 4. Conventions

- Titles are short, two to four words; descriptions are one sentence
  ending with a full stop.
- French uses the typographic apostrophe (’) and a non-breaking space
  before `:`; English uses none.
- Dates (`{date}`) are formatted by the client in the interface locale.
- `{level}` and `{pack}` are themselves translated before substitution.
